# Hoja & Barro · Tienda de plantas y cerámica

Página web estática de una tienda ficticia de plantas de interior y cerámica artesanal.

Hecha solo con **HTML y CSS**, sin JavaScript ni dependencias (las fuentes se cargan desde Google Fonts).

## Cómo verla

Abre `index.html` en el navegador.

## Secciones

- Hero con ilustración SVG animada
- Ventajas, categorías y productos destacados
- Sobre nosotros
- Newsletter
- Pie con la versión actual

## Estructura

```
index.html   Marcado de la página
styles.css   Estilos (variables de color, responsive)
CHANGELOG.md Historial de versiones
```

## Versión

La versión actual aparece en el pie de la página. Consulta el [CHANGELOG](CHANGELOG.md).

> Los nombres, direcciones y precios son ficticios.
